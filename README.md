# ✨ Task Master (Glassmorphism Edition)

A beautifully designed, fully responsive To-Do List application. This project features a modern **Glassmorphism UI** with smooth animations, a dark gradient theme, and an AI-powered summary feature.

## 🎨 Features

*   **💎 Super Glassmorphism UI**: Frosted glass effects, premium gradients, and translucent borders.
*   **📱 Fully Responsive**: Looks stunning on mobile, tablet, and desktop.
*   **⚡ Smooth Animations**: Tasks slide in/out, and buttons have satisfying hover effects.
*   **🧠 AI Summary**: (Optional) Integrated placeholder for OpenAI-powered daily task summaries.
*   **💾 Local Storage**: Your tasks are saved automatically to your browser.

## 🛠️ Tech Stack

*   **HTML5**
*   **CSS3** (Variables, Backdrop Filter, Flexbox, Animations)
*   **Vanilla JavaScript** (DOM Manipulation, LocalStorage)

## 🚀 How to Run

1.  Clone the project or download the folder.
2.  Open `index.html` in your browser.
    *   *Recommended*: Use a local server like Live Server or `npx serve` for the best experience.

## 📸 Usage

*   **Add Task**: Type in the input and click "Add Task" or press Enter.
*   **Complete**: Click the text to toggle completion status.
*   **Edit**: Click the ✏️ icon.
*   **Delete**: Click the ❌ icon.
